# AI-100-Projects

> **Build 100 Products with AI. Find the Ones Worth Building.**  
> 用 AI 完成 100 个产品，寻找真正值得做的项目。

## 项目简介

这是一个长期进行的 AI 产品实践与探索项目。

我们希望借助 AI 的能力，从真实需求出发，持续发现值得解决的问题，并将有潜力的想法做成完整、可使用、可部署、可验证商业价值的产品。

这里的「100 个项目」是一个长期探索目标，而不是一份已经确定、不能更改的开发清单。

## 我们想做什么

- 发现真实需求，关注普通用户、内容创作者、开发者和小微商家的实际问题。
- 筛选值得做的产品，评估用户痛点、市场空间、付费意愿、竞争情况和获客难度。
- 借助 AI 完成开发，探索 AI 在产品设计、编码、测试、部署和运营中的实际能力。
- 完成真正可用的产品，不止做 Demo。
- 验证商业价值，寻找可持续的收入来源。
- 持续复盘开发成本、用户反馈和商业验证结果。

## 项目筛选原则

一个想法进入正式开发前，应尽可能回答：
1. 谁会使用？
2. 解决什么真实问题？
3. 相比现有方案有什么差异？
4. 用户为什么付费？
5. 市场和竞品情况如何？
6. 如何获得第一批用户？
7. 能否由个人或小团队完成？
8. 投入、维护和合规成本是否可控？

如果调研后发现需求不成立，及时放弃也是项目成果的一部分。

## 项目状态

| 状态 | 说明 |
|---|---|
| 候选池 | 已记录，等待评估 |
| 调研中 | 正在验证需求、竞品和商业机会 |
| 产品规划中 | 正在确定定位、需求、功能和规则 |
| 准备开发 | 产品范围和技术方案已确认 |
| 开发中 | 正在设计、编码或测试 |
| 已完成 | 核心功能完成并具备可交付成果 |
| 已上线 | 已部署，用户可以实际使用 |
| 商业验证中 | 正在验证付费意愿、收入和获客 |
| 已暂停 / 已归档 | 暂时停止或经评估后不再推进 |
