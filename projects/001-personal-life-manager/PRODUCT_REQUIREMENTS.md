# 拾记产品需求文档（PRD）

- 版本：1.0
- 状态：核心方向与主要规则已确认；市场调研、交互细节和技术方案待完成
- 更新时间：2026-11-19

## 1. 产品概述

拾记是一款面向个人用户的个人信息收纳与生活管理工具。用户可以保存证件、文件和重要信息，管理生活事项、日历、提醒、健康记录、生活资产及账号密码，并在授权设备之间安全同步所选数据。

### 核心价值

- **保存**：重要资料和文件有统一的存放位置。
- **管理**：资料、事项、日期、健康记录和生活资产可以分类并建立关联。
- **提醒**：重要日期、到期事项、周期任务不容易遗漏。
- **查找**：通过全局搜索快速找到所需内容。
- **保护**：本地优先、端到端加密、用户自主决定同步范围。
- **跨设备**：同一账号可在微信小程序、抖音小程序等多端使用自己的资料。

产品不要求用户先建立完整个人档案。用户可以从任意模块快速新增，非必要字段允许跳过，之后再补充。

## 2. 平台与账号体系

### 平台

- 首发：微信小程序。
- 后续：抖音小程序等多平台。
- Web：仅管理员使用的管理后台，不作为普通用户 Web 客户端。

### 账号与设备

- 使用产品必须联网注册和登录，账号由服务器统一管理。
- 登录后，用户的本地资料仍保存在本机；普通资料不会因登录而自动上传。
- 同一账号支持多台设备同时登录和同步。
- 一台设备同一时间只能登录一个拾记账号；切换账号需要先退出当前账号。
- 多设备使用仅限同一用户自己的账号和资料，不代表家庭共享或多人协作。
- 支持查看已登录设备及管理设备授权；具体撤销和密钥轮换流程由安全方案定义。

## 3. 信息架构与导航

采用固定 4 Tab：

1. **首页**：生活概览、今日事项、近期提醒、常用入口。
2. **资料**：证件、文件、生活记录、健康记录、生活资产及保险箱入口。
3. **日历**：待办、日程、生日、纪念日、周期任务和提醒。
4. **我的**：账号、设备、云空间、同步、安全、备份、通知和通用设置。

保险箱在资料体系中保留独立入口和独立安全边界，不因放在“资料”入口下而与普通资料混合处理。

新增方式同时支持：
- 从统一入口上传或提交内容，先识别类型，再识别具体字段。
- 在各业务模块内直接新增对应内容。

## 4. 功能模块范围

以下模块均已确认纳入产品范围，具体页面、字段和交付顺序在后续设计阶段细化。

### 4.1 首页

- 生活概览、今日待办、近期提醒、逾期事项。
- 近期到期资料、重要日期、最近添加内容。
- 常用模块和快捷新增入口。

### 4.2 个人资料与文件

- 身份证、护照、驾驶证、居住证/签证、银行卡、学历及资格证书。
- 合同、保险单、票据、报告、图片、PDF 和其他重要文件。
- 个人档案、生活记录、备注、标签、分类和关联事项。
- 原始文件完整保留；另生成缩略图或预览副本。
- 支持原文件下载、导出和恢复；预览生成失败不得影响原文件。

### 4.3 生活事项与日历

- 待办、日程、生日、纪念日、缴费、订阅续费和重要日期。
- 周期任务、自定义重复规则、完成历史。
- 提前提醒、重复提醒、延后提醒和通知管理。
- 资料有效期可关联或生成日历事项和提醒。

### 4.4 私密保险箱

- 网站/软件账号、密码、Wi-Fi、软件授权码、恢复代码。
- API Key、SSH、服务器、数据库凭证和安全笔记。
- 独立主密码、独立密钥体系、自动锁定和恢复密钥。
- 支持客户端加密后的云同步；其他设备必须获得安全授权后才能解密。
- 保险箱内容不得以明文进入普通搜索索引、通知正文、日志或服务端。

### 4.5 健康记录

- 生理周期、体重、血压、睡眠、运动。
- 用药、体检、疫苗、复查和健康报告。
- 健康记录默认本地保存；用户可按同步规则主动选择云同步。
- 健康趋势和预测仅作为记录参考，不替代医疗建议。

### 4.6 生活资产

- 车辆、房屋、家电/设备、宠物及自定义资产。
- 购买信息、保修期限、保险、维修、保养、年检和维护历史。
- 资产可关联文件、凭证、费用和提醒。

### 4.7 自动识别与快速新增

- 对图片、PDF 和支持的文件先识别内容类型。
- 根据识别出的类型再提取对应字段，例如姓名、证件号码、有效期、日期或金额。
- 展示识别结果供用户确认、修改后再保存。
- 无法识别或识别置信度不足时允许手动选择类型和填写。
- 支持各模块独立手动新增。
- 当前不接入 AI；识别能力优先通过本地文件解析、OCR 和规则实现，具体技术选型待评估。

### 4.8 全局搜索、分类与关联

- 一个全局搜索入口，跨模块查找资料、文件、事项、健康记录和资产。
- 支持按模块、类型、分类、标签和时间筛选。
- 搜索结果可跳转到原始内容。
- 保险箱遵循独立解锁规则；未解锁内容不进入普通搜索结果，解锁后按安全设计提供搜索。
- 系统预设分类与用户自定义分类并存。
- 支持标签；资料、事项、文件和资产可建立关联。

### 4.9 云空间与多设备同步

- 普通资料默认仅本地保存。
- 用户可按模块、分类、单条记录或单个文件开启同步。
- 保险箱支持客户端加密云同步。
- 同一账号多设备登录，支持查看、管理、同步和下载自己的资料。
- 提供同步状态、暂停/恢复、失败重试、设备管理和冲突处理。
- 同步冲突采用版本管理并提示用户处理，不静默覆盖。
- 历史版本长期保留；云端历史版本占用计入云空间容量。

### 4.10 数据管理

- 手动创建本地完整备份、选择保存位置、从备份恢复。
- 备份文件本身不额外加密；保险箱数据在备份中仍保持保险箱自身加密状态。
- 恢复前校验完整性并提示覆盖范围。
- 删除内容先进入回收站，支持恢复和永久删除。
- 本地与云端的删除状态按同步规则协调，避免旧设备重新上传已删除内容。

### 4.11 提醒与通知

- 小程序订阅消息（微信首发，抖音等平台按平台能力适配）。
- 云端推送作为多设备补充。
- 端内提醒、订阅消息与云端推送相互补充；需要通知去重。
- 支持提醒时间、提前提醒、重复规则、通知中心和通知偏好。
- 提醒送达受设备权限、联网、后台限制、省电策略和设备状态影响，不承诺绝对准时。

## 5. 数据存储与加密原则

### 本地优先

- 普通资料默认写入本地。
- 登录只建立账号身份，不代表自动上传个人资料。
- 用户明确选择同步后，所选数据才进入云同步队列。
- 本地查看、编辑和新增不依赖云服务在线。

### 端到端加密

拾记采用统一的端到端加密方向：敏感内容在客户端加密后上传，服务器仅保存密文，不持有用户数据的解密密钥。

覆盖范围：
- 普通个人资料、生活事项、健康记录、生活资产。
- 原始文件、预览副本和历史版本。
- 保险箱使用独立密钥体系和独立主密码/恢复密钥。

服务端仅处理账号、订单、设备、容量、同步路由和必要运行信息等服务管理数据，并尽量减少元数据暴露。搜索索引、OCR、预览生成和内容比较在客户端完成。

密码学算法、密钥派生、密钥轮换、设备授权、撤销、恢复及同步协议必须采用成熟标准和经过审查的实现，不自行发明密码学协议。该方向是产品架构决策，不代表安全实现已经完成或通过审计。

## 6. 商业模式与云空间

- 本地存储和核心生活管理功能免费。
- 不采用传统会员制，不以会员身份限制基础功能。
- 云空间收费，支持月度/年度订阅和一次性购买固定容量。
- 订阅容量与一次性购买容量叠加计算。
- 一次性购买容量长期保留；订阅容量在订阅有效期内提供。
- 云空间容量档位、价格、订阅周期权益及长期存储成本待调研测算。

### 订阅到期

- 到期后保留云端已有数据，不立即删除。
- 用户仍可查看、下载和导出已有云端数据。
- 暂停新增上传和新的云同步。
- 本地功能不受影响。
- 订阅容量失效后，若已用空间超过剩余容量，保留已有数据并限制新增和同步；重新购买后按新容量恢复服务。

## 7. 删除、版本与恢复

- 删除内容先进入回收站，支持恢复和永久删除。
- 回收站保留期限和自动清理规则尚待确定。
- 历史版本长期保留，支持查看、比较和恢复；恢复产生新版本，不覆盖历史。
- 发生并发修改冲突时，保留冲突版本并提示用户选择或合并。
- 永久删除时应明确说明会影响的当前版本、历史版本、附件和云端副本。

## 8. Web 管理后台

Web 仅供管理员使用，不提供普通用户的 Web 资料管理客户端。

管理后台的管理对象包括账号、云空间与订单、设备、存储资源、系统配置及必要的运行审计。管理员不应获得读取用户端到端加密资料明文的能力。

详细角色、权限、审计范围和运营流程待后台设计阶段细化。

## 9. 明确不做

- 家庭成员共享、多人共同管理资料或事项。
- AI 自动分类、AI 助手或 AI 自动录入（当前阶段不接入 AI）。
- 社交网络、内容社区和公开分享。
- 将基础生活管理功能设置为会员专属。
- 普通用户 Web 客户端（当前 Web 定位仅为管理员后台）。

## 10. 待调研与待设计

这些事项不是已承诺功能或开发任务，完成研究后再形成决策：
- 市场、竞品、用户访谈和需求优先级。
- 首发模块的交付顺序和详细验收标准。
- 回收站保留期限、容量超限和最终清除规则。
- 云空间容量、价格、对象存储和历史版本成本。
- 账号找回与端到端加密数据恢复之间的边界。
- 密钥派生、密钥轮换、设备授权/撤销、同步冲突协议和安全威胁模型。
- 客户端、服务端、数据库、推送和文件存储技术选型（小程序端已选型 uni-app）。
- 适用地区的数据保护、隐私、支付及其他合规评估。

## 11. 验收原则

- 微信小程序首发平台的核心体验与归档 App 功能基线一致，视觉按 `设计图/` 落地；抖音等多平台按平台能力适配。
- 必须联网注册、登录；本地数据不因登录而自动上传。
- 用户能清楚区分本地数据、待同步数据和云端密文。
- 未选择同步的普通资料不会上传。
- 服务端无法解密用户个人内容。
- 备份恢复、回收站、版本冲突和设备授权有明确可验证的行为。
- 保险箱未解锁时，敏感内容不出现在普通列表、搜索结果和通知正文。
- 云空间到期不影响本地数据，已有云端数据可查看、下载和导出。
