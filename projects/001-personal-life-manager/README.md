## 产品定位
面向普通个人用户的生活信息管理工具，集中管理证件资料、重要文件、生活事项、日期提醒、健康记录、生活资产和私密信息。它不是单纯的待办清单，也不是普通网盘，而是通过资料、事项、日期和提醒之间的关联，帮助用户减少遗忘和重复整理。

## 已确定原则
1. 本地优先，默认本地保存，不强制注册。
2. 核心生活管理功能免费，不以会员身份限制基础功能。
3. 云端存储、备份和多设备同步按云空间收费，价格待成本测算。
4. 云同步采用客户端加密，服务端只保存密文，不持有解密密钥。
5. 默认不自动上传，用户可按模块、分类、单条记录和单个文件选择同步范围。
6. 快速录入优先，非必要字段可跳过，后续再补充。
7. 提供数据导出、备份、删除和迁移能力。

## 当前待决策
- 4 个还是 5 个底部导航，需结合使用频率和可用性验证。
- 新增入口采用全局按钮、页面内按钮还是组合方式。
- 首发版本的健康记录、生活资产和保险箱边界。
- 密钥恢复、设备授权、同步冲突和云端删除方案。
- 云空间容量档位、价格、流量和备份成本。
- Web 端是否首发，以及其可访问的数据范围。

## 当前明确不做
