# 拾记产品规则与关键业务约束

- 版本：1.0
- 状态：已确认规则；标注“待设计”的内容不得擅自补成确定行为

## 1. 记录与录入

1. 用户不需要先创建完整个人档案。
2. 非必要字段允许跳过。
3. 快速新增优先，创建后可补充和完善资料。
4. 不同资料类型使用适合自身场景的字段。
5. 资料记录与附件是不同的数据对象，附件可独立管理。
6. 自动新增先识别内容类型，再识别该类型对应的字段。
7. 自动识别结果必须让用户确认、修改后再保存。
8. 用户也可以直接进入各模块手动新增。

## 2. 账号与设备

1. 注册和登录必须联网，账号由服务器统一管理。
2. 同一账号允许多台设备登录。
3. 一台设备同一时间只能登录一个账号。
4. 多设备登录仅代表同一用户使用自己的资料，不代表与其他用户共享。
5. Windows 与 Android 同步开发、同步发布；iOS 为二期。
6. Web 仅作为管理员后台，不提供普通用户 Web 客户端。

## 3. 四 Tab 导航

固定底部导航为：
1. 首页：生活概览和快捷入口。
2. 资料：个人资料、文件、健康、资产和保险箱入口。
3. 日历：事项、日期和提醒。
4. 我的：账号、设备、云空间、安全和设置。

保险箱虽然从“资料”进入，仍必须保持独立的安全边界。

## 4. 本地优先与云同步

1. 普通资料默认保存在本地。
2. 登录不代表自动上传资料。
3. 用户可按模块、分类、单条记录或单个文件开启云同步。
4. 未被用户选择同步的数据不得上传。
5. 父级同步关闭时，子级不得绕过限制上传。
6. 暂停同步、停止续费、删除云端副本和删除本地数据是不同操作。
7. 同步失败不能破坏本地数据，必须提供状态和重试能力。
8. 保险箱支持客户端加密云同步。
9. 多设备同步包括下载和查看用户自己的资料。

## 5. 加密与密钥

1. 普通个人数据采用端到端加密：客户端加密后上传，服务端只保存密文，不持有解密密钥。
2. 加密范围包括普通资料、事项、健康记录、资产、文件、预览副本和历史版本。
3. OCR、预览生成、内容搜索和版本差异比较在客户端完成。
4. 服务端只处理账号、订单、设备、容量、同步路由和必要运行信息等最少服务元数据。
5. 保险箱使用独立主密码、独立密钥体系和恢复密钥。
6. 保险箱密文可云同步；其他设备必须经过安全授权才能解密。
7. 密钥派生、轮换、恢复、设备撤销等必须使用成熟标准和经过审查的实现，不自行发明密码学协议。
8. 账号密码找回不等于能够恢复端到端加密数据；具体恢复关系必须在安全设计中明确。
9. 任何密码、密钥、证件内容和健康内容不得进入普通日志、通知正文或分析事件。

## 6. 本地备份与恢复

1. 备份由用户手动创建，不要求自动备份。
2. 用户可以选择备份文件保存位置。
3. 备份文件本身不额外加密。
4. 保险箱内容在备份中仍保持保险箱自身加密状态，不导出明文密码。
5. 备份包含恢复数据所需的记录、附件、分类、标签和关联关系。
6. 恢复前校验完整性，并说明可能覆盖的内容。
7. 恢复前要求用户确认；恢复失败不能破坏现有可用数据。
8. 导出未加密备份时，明确提示文件可能包含敏感个人资料，提醒用户妥善保管。

## 7. 删除与回收站

1. 普通删除先进入回收站。
2. 回收站支持查看、恢复和永久删除。
3. 恢复后保留原有分类、标签和关联关系。
4. 永久删除前进行二次确认。
5. 已开启同步的数据，其删除状态需要协调到其他设备，避免旧数据重新上传。
6. 回收站保留期限、自动清理时间及云端最终清除策略待设计，不得擅自设定。

## 8. 搜索、分类与关联

1. 提供统一全局搜索入口，跨模块搜索。
2. 搜索支持按模块、类型、分类、标签和时间筛选。
3. 搜索结果可以跳转到对应内容。
4. 搜索索引优先在客户端建立和维护。
5. 保险箱未解锁时不显示其敏感内容；解锁后的搜索遵循独立安全规则。
6. 系统分类与用户自定义分类并存。
7. 支持标签和资料、事项、文件、资产之间的关联。

## 9. 提醒与通知

1. 同时支持设备本地提醒和云端推送。
2. 本地提醒优先，云端推送作为多设备补充。
3. 需要避免同一设备因本地与云端渠道收到重复通知。
4. 用户关闭通知权限时，说明对提醒的影响。
5. 后台策略、设备关机、省电模式、网络和权限状态可能影响送达，不承诺绝对准时。
6. 通知正文不得暴露保险箱密码、密钥或其他高敏感内容。

## 10. 文件与预览

1. 用户上传的原始文件完整保留，不主动压缩或覆盖。
2. 支持生成缩略图或预览副本，提升浏览效率。
3. 预览副本与原文件分开管理并建立关联。
4. 预览生成失败不得影响原文件保存。
5. 原文件支持下载、导出和恢复。
6. 删除原文件时，关联预览副本纳入删除处理。

## 11. 云空间与商业规则

1. 本地存储和核心生活管理功能免费。
2. 云空间采用月度/年度订阅与一次性购买并行。
3. 订阅容量和一次性购买容量叠加。
4. 一次性购买容量长期保留；订阅容量仅在订阅有效期内提供。
5. 订阅到期后保留已有云端数据，允许查看、下载和导出。
6. 订阅到期后限制新增上传和云同步，本地功能不受影响。
7. 若订阅容量失效导致已用空间超出剩余容量，保留已有数据并暂停新增和同步。
8. 云空间具体容量、价格、套餐规则及成本待调研测算。

## 12. 版本与同步冲突

1. 数据修改形成版本，历史版本长期保留。
2. 支持查看、比较和恢复历史版本。
3. 恢复历史版本时生成新版本，不覆盖原历史。
4. 并发修改发生冲突时，不静默覆盖。
5. 保留冲突版本并提示用户选择或合并。
6. 文件也纳入版本管理。
7. 云端历史版本占用计入云空间容量。
8. 版本数据结构、差异算法和冲突协议待技术设计。

## 13. Web 管理后台

1. Web 仅供管理员使用。
2. 管理后台用于账号、设备、云空间、订单、存储资源、系统配置和必要审计管理。
3. 管理员不应具备读取用户端到端加密内容明文的能力。
4. 后台角色、权限和操作审计范围待详细设计。

## 14. 明确不做

- 家庭成员共享和多人共同管理。
- 当前阶段接入 AI 助手、AI 自动分类或 AI 自动录入。
- 社交网络、内容社区和公开分享。
- 普通用户 Web 客户端。
- 以传统会员身份限制基础生活管理功能。
