## 0. 一句话定位

> **把重要的事存进来，到时间提醒你，需要时 3 步找到。**
> 保存 → 提醒 → 查找，三个闭环跑通，拾记才算"能用"。

### 1.3 可用性问题（"不方便用"的根源）

1. **单一事实源缺失**：用户想知道"接下来该干什么"，要翻首页待办、日历、订阅页、证件详情四五个地方。→ 解决：统一时间线（§4.2）。
2. **入口不成体系**：同一类东西（时间相关）入口分散在日程卡、图例、宫格。→ 解决：按心智模型归位（§3）。
3. **可见不可点 / 不可见可点**：设置里"主题/字体"行长得能点实际无响应；日历图例长得像图例实际能点。→ 解决：可交互性必须视觉自明（§2 原则 4）。
4. **假数据破坏信任**：会员横幅、假容量、假设备。真实产品里这些等于欺骗。→ 解决：M0 起全部接真实数据，空态代替假数据。
5. **新增路径单一**：只有"新增记录"一个入口，想记个待办也得走"记录"。→ 解决：万能新增（§4.1）。

## 2. 设计原则（全团队验收时逐条对照）

| # | 原则 | 验收方式 |
|---|---|---|
| P1 | **3 秒新增**：从点击 + 到保存，普通记录 ≤3 步、目标 ≤10 秒 | 可用性测试计时 |
| P2 | **3 步可达**：任何一条已存内容 ≤3 次点击到达 | 页面树深度审计 |
| P3 | **单一心智模型**：时间相关 → 日历 Tab；内容相关 → 资料 Tab；"现在该干嘛" → 首页；账号与全局 → 我的 | IA 评审 |
| P4 | **可见即可点**：不可交互的元素不得使用行/箭头样式；可交互的必须有反馈态 | UI 走查 |
| P5 | **空态即引导**：每个列表页必须设计空状态（一句话 + 一个行动按钮） | 设计评审 |
| P6 | **本地优先可见**：每条内容带同步状态徽章（仅本地 / 待同步 / 已同步），呼应验收原则 | 详情页走查 |
| P7 | **真实数据**：不允许任何假数字、假会员、假设备出现在 UI | 代码评审 |
| P8 | **不做清单铁律**：AI、家庭共享、社交、会员限制、普通用户 Web —— 任何提案不得触碰 | 评审红线 |

## 4. 核心流程设计

### 4.1 万能新增（P0）

```
点 FAB
 └─ 底部抽屉（不跳页，单手可达）
     ├─ 📝 文字记录   → 记录表单（标题必填，其余可跳过）
     ├─ 📷 拍照/相册  → 识别流程（见 4.2）
     ├─ 📎 上传文件   → 识别流程
     ├─ ☑️ 待办      → 标题 + 截止日(默认明天) + 提醒(默认当天 9:00)
     ├─ 📅 日程      → 标题 + 开始/结束 + 提前提醒
     └─ 💳 证件      → 类型选择 → 字段表单
```

规则：任何表单**必填字段 ≤2 个**；保存后落本地并弹出"要不要设提醒？"（识别到有效期/日期时）；遵守"非必要字段允许跳过"。

### 4.2 自动识别流程（P1，本地 OCR + 规则，不接 AI）

```
拍照/选文件
 → 本地解析（OCR + 文件元数据）
 → 判定内容类型（证件/发票/报告/…），显示置信度
     ├─ 置信度 ≥ 阈值：直接进入该类型字段表单（已预填）
     └─ 置信度不足：让用户从类型列表选择，再进表单
 → 用户确认/修改字段 → 保存
 → 识别到有效期 → 追问"到期前 30 天提醒？"（一键开启）
```

识别失败永远不阻塞保存：文件按普通文件入库，字段留空可后补（PRD §4.7）。

### 4.3 统一时间线「接下来」（P0，首页核心组件）

- 数据源聚合：待办 + 日程 + 缴费/续费 + 生日/纪念日 + 资料到期，按时间排序。
- 排序规则：**逾期（红色置顶）→ 今天 → 明天 → 7 天内 → 之后折叠**。
- 每行：类型图标 + 标题 + 时间语义（"已逾期 2 天"/"还有 26 天"）+ 快捷操作（完成 / 延期 1 天 / 查看）。
- 空状态："未来 7 天没有安排。添加一个待办 →"。

### 4.4 提醒中心（P0）

- 三个分组：逾期 / 今日 / 已延期（+历史折叠）。
- 行内操作：完成、延期（1 天/1 周/自定义）、查看详情。
- 与系统通知的关系：通知只是"敲门"，处理动作全部在提醒中心完成；本地与云推送按规则去重（PRODUCT_RULES §9）。

### 4.5 三个业务闭环

| 闭环 | 流程 | 闭环完成的标志 |
|---|---|---|
| 保存 | 新增 → 识别/填写 → 入库 → 建议提醒 | 内容出现在资料 Tab + 搜索可达 |
| 提醒 | 创建带日期内容 → 自动生成提醒 → 通知 → 提醒中心 → 处理（完成/续期/延期） | 处理动作改变内容状态并写历史 |
| 查找 | 搜索/分类/标签 → 结果分组 → 详情 → 关联内容互跳 | 3 步内到达（P2 原则） |

### 4.6 保险箱交互（P1）

- 首次进入：设置主密码（强度检测）→ 生成恢复密钥（强制用户抄写确认）。
- 解锁：主密码；后台切换或息屏 → 自动锁定（默认 5 分钟，可选 1/5/15/立即）。
- 新设备：必须凭旧设备授权或恢复密钥才能解密（呼应安全决策）。
- 未解锁状态：保险箱在资料 Tab 只显示入口卡 + 条目数量，不显示任何标题/内容；不进普通搜索（PRODUCT_RULES §8.5）。

### 4.7 同步与冲突（P2，依赖安全方案评审）

- 每条内容详情页显示同步状态徽章；列表页提供"仅看未同步"筛选。
- 冲突：不静默覆盖，弹对比视图让用户选择保留/合并（PRD §7）。
- 云空间到期：横幅提示"云端只读"，本地功能完全不受限（PRODUCT_RULES §11.5-6）。

## 7. 状态设计规范（每页必备）

| 状态 | 要求 |
|---|---|
| 空态 | 一句话说明 + 一个 CTA 按钮（如"还没有证件。添加第一张 →"） |
| 加载 | 骨架屏；本地数据 <100ms 可直接渲染 |
| 错误 | 区分：本地错误（可重试）/ 无网络（说明哪些功能可用）/ 云端错误（不影响本地操作） |

| 权限关闭 | 通知权限关闭时，在提醒中心顶部说明影响并给系统设置入口（RULES §9.4） |

## 10. 验收与度量（M1 出口）

- **激活**：新用户 24h 内完成 ≥1 条带提醒的内容。
- **效率**：新增到保存 ≤10s（P50）；搜索到目标 ≤15s（P50）；任意内容 ≤3 步。
- **提醒**：本地提醒准点触发率 ≥99%（设备允许后台时）；逾期项 100% 出现在时间线置顶。
- **信任**：0 处假数据；每条内容可辨"仅本地/已同步"；回收站可恢复任意删除项。
